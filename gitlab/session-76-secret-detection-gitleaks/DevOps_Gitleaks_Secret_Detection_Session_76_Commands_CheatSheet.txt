# docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v "$PWD:/repo" \
  -w /repo \
  ghcr.io/gitleaks/gitleaks:v8.30.1 \
  git --redact --verbose .

Explanation:
Runs Gitleaks against the mounted Git repository and scans its Git history while redacting detected secret values and showing detailed findings.

Options:
- --rm = remove: Automatically removes the container when it exits.
- --user = user: Runs the container process with the user ID and group ID returned by the host id commands.
- $(...) = command substitution: Runs the command inside the parentheses and inserts its output into the Docker command.
- -u in id -u = --user (user): Prints only the effective user ID.
- -g in id -g = --group (group): Prints only the effective group ID.
- -v = --volume (volume): Mounts "$PWD" from the host at /repo inside the container.
- -w = --workdir (working directory): Sets /repo as the working directory inside the container.
- --redact = redact: Redacts detected secret values from Gitleaks output.
- --verbose = verbose: Shows more detailed information about detected findings.

# gitleaks git . || true

Explanation:
Runs a Gitleaks Git-history scan against the current repository, but forces the overall shell command to succeed if Gitleaks returns a non-zero exit status.

Options:
- || = shell logical OR operator: Runs true only if the Gitleaks command fails, which hides the failure from the shell and can disable the security gate.

# docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v "$PWD:/repo" \
  -w /repo \
  ghcr.io/gitleaks/gitleaks:v8.30.1 \
  git \
  --redact \
  --report-format json \
  --report-path gitleaks-report.json \
  .

Explanation:
Runs a Git-history secret scan and writes the scan report to gitleaks-report.json in JSON format while redacting detected secret values.

Options:
- --rm = remove: Automatically removes the container when it exits.
- --user = user: Runs the container process with the user ID and group ID returned by the host id commands.
- $(...) = command substitution: Runs the command inside the parentheses and inserts its output into the Docker command.
- -u in id -u = --user (user): Prints only the effective user ID.
- -g in id -g = --group (group): Prints only the effective group ID.
- -v = --volume (volume): Mounts "$PWD" from the host at /repo inside the container.
- -w = --workdir (working directory): Sets /repo as the working directory inside the container.
- --redact = redact: Redacts detected secret values from Gitleaks output.
- --report-format json = report format: Writes the report using JSON format.
- --report-path gitleaks-report.json = report path: Saves the generated report as gitleaks-report.json.
