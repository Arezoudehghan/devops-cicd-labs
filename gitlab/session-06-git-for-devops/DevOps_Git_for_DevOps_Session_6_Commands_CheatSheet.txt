- --force = force update: Disables the normal non-fast-forward protection for the push.
------------------------------------------------------------

------------------------------------------------------------
# git commit --amend

Explanation:
Replaces the most recent commit using the current staged content and opens the editor for the commit message.

Options:
- --amend = amend commit: Replaces the tip commit with a new commit.
------------------------------------------------------------

------------------------------------------------------------
# git commit --amend -m "correct commit message"

Explanation:
Replaces the most recent commit and sets its message to correct commit message.

Options:
- --amend = amend commit: Replaces the tip commit with a new commit.
- -m = --message (message): Uses the following text as the commit message.
- "correct commit message" = option value: The replacement commit message.
------------------------------------------------------------

------------------------------------------------------------
# git restore FILE

Explanation:
Restores the working-tree file represented by FILE from the staging area.
------------------------------------------------------------

------------------------------------------------------------
# git restore --staged FILE

Explanation:
Removes the file represented by FILE from the staging area while keeping its working-tree changes.

Options:
- --staged = staging area: Restores the index entry instead of the working-tree file.
------------------------------------------------------------

------------------------------------------------------------
# git reflog

Explanation:
Displays the local reflog, including recent movements of HEAD and other references.
------------------------------------------------------------

------------------------------------------------------------
# git log --oneline -5

Explanation:
Shows at most the five most recent commits in compact one-line format.

Options:
- --oneline = one-line format: Shows each commit in a compact single-line form.
- -5 = --max-count=5 (maximum count): Limits the output to five commits.
------------------------------------------------------------

------------------------------------------------------------
# git status -sb

Explanation:
Shows compact repository status and includes branch and tracking information.

Options:
- -s = --short (short): Uses the compact short status format.
- -b = --branch (branch): Shows branch and tracking information in short format.
------------------------------------------------------------

------------------------------------------------------------
# git log origin/main..HEAD --oneline

Explanation:
Shows commits that are reachable from HEAD but not from origin/main, which can reveal local commits not yet pushed.

Options:
- --oneline = one-line format: Shows each commit in a compact single-line form.
------------------------------------------------------------
