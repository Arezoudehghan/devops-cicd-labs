# printf '%s' "$NEXUS_PULL_PASSWORD" |
ssh -i "$SSH_PRIVATE_KEY"
"$DEPLOY_USER@$DEPLOY_HOST"
"docker login '$NEXUS_REGISTRY'
-u '$NEXUS_PULL_USER'
--password-stdin"

Explanation:
Sends NEXUS_PULL_PASSWORD through SSH standard input and runs docker login on the remote deployment host. SSH uses the private key referenced by SSH_PRIVATE_KEY.

Options:
- %s = string format specifier: Prints the password value without adding a newline.
- | = pipe operator: Sends printf output to the standard input of ssh.
- -i = identity_file: Tells ssh which private key file to use.
- -u = --username: Sets the Docker registry username in the remote docker login command.
- --password-stdin = password from standard input: Makes the remote docker login read the password from standard input.

# ssh -i "$SSH_PRIVATE_KEY"
"$DEPLOY_USER@$DEPLOY_HOST"
"docker rm -f myapp || true"

Explanation:
Connects to the deployment host and force-removes the container named myapp. If docker rm fails, true makes the remote command return success.

Options:
- -i = identity_file: Tells ssh which private key file to use.
- -f = --force: Forces removal of the running container in docker rm.
- || = OR operator: Runs true only if docker rm returns a non-zero status.

# ssh -i "$SSH_PRIVATE_KEY"
"$DEPLOY_USER@$DEPLOY_HOST"
"docker run -d
--name myapp
-p 8088:8080
'$IMAGE'"

Explanation:
Connects to the deployment host and starts IMAGE as a detached container named myapp with host port 8088 mapped to container port 8080.

Options:
- -i = identity_file: Tells ssh which private key file to use.
- -d = --detach: Runs the container in the background.
- --name = container name: Sets the container name to myapp.
- -p = --publish: Publishes a container port to the host.
- 8088:8080 = publish value: Maps host port 8088 to container port 8080.
