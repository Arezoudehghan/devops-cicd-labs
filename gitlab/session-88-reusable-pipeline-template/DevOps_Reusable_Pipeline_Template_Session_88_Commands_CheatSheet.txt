# docker build -t myapp:$CI_COMMIT_SHORT_SHA .

Explanation:
Builds a Docker image from the current directory and tags it as `myapp` with the current GitLab short commit SHA.

Options:
- -t = --tag (tag): Sets the image name and optional tag in `name:tag` format.
- $CI_COMMIT_SHORT_SHA = GitLab CI/CD variable: Supplies the shortened commit SHA as the image tag.
- . = build context: Uses the current directory as the Docker build context.

# docker build -t "$IMAGE_NAME:$CI_COMMIT_SHORT_SHA" .

Explanation:
Builds a Docker image from the current directory and uses CI/CD variables to create the image name and tag.

Options:
- -t = --tag (tag): Sets the image name and optional tag in `name:tag` format.
- $IMAGE_NAME = shell variable: Supplies the image repository or image name.
- $CI_COMMIT_SHORT_SHA = GitLab CI/CD variable: Supplies the shortened commit SHA as the image tag.
- . = build context: Uses the current directory as the Docker build context.

Options:
- -a = --annotate (annotate): Creates an unsigned annotated tag object.

# docker build -t "$[[ inputs.registry-image ]]:$CI_COMMIT_SHORT_SHA" .

Explanation:
Builds a Docker image from the current directory, using a GitLab CI/CD component input for the image name and the short commit SHA for the tag.

Options:
- -t = --tag (tag): Sets the image name and optional tag in `name:tag` format.
- $[[ inputs.registry-image ]] = GitLab CI/CD input interpolation: Inserts the value of the component input named `registry-image`.
- $CI_COMMIT_SHORT_SHA = GitLab CI/CD variable: Supplies the shortened commit SHA as the image tag.
- . = build context: Uses the current directory as the Docker build context.
