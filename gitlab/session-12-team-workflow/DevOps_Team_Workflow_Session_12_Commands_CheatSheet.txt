# git log --oneline --graph --decorate --all

Explanation:
Shows commit history in a compact graph and includes references from all available branches and refs.

Options:
- --oneline = one-line format: Displays each commit as an abbreviated commit ID followed by its subject on one line.
- --graph = graph display: Draws an ASCII graph of branch and merge history.
- --decorate = reference decoration: Shows branch, tag, and other reference names next to commits.
- --all = all references: Shows commits reachable from all refs instead of only the current history.
