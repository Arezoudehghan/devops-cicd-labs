# git push origin main

Explanation:
Pushes the local main branch to the remote named origin.
------------------------------------------------------------
# git switch main

Explanation:
Switches the working directory to the local main branch.
------------------------------------------------------------
# git pull --ff-only origin main

Explanation:
Fetches changes from origin/main and updates the current branch only if Git can fast-forward without creating a merge commit.

Options:
- --ff-only = fast-forward only: Refuses the pull if a fast-forward update is not possible.
------------------------------------------------------------

# cat > app.txt <<'EOF'
Application: Branching Strategy Lab
Version: 1.0.0
Status: Production
EOF

Explanation:
Creates or overwrites app.txt with the exact text inside the quoted here-document.

Options:
- > = output redirection: Redirects the command output to app.txt and overwrites the file.
- <<'EOF' = quoted here-document: Supplies the following lines as standard input until the closing EOF marker, without shell variable or command expansion.

Explanation:
Shows the latest five commits reachable from release/1.1 in a compact one-line format.

Options:
- --oneline = one-line format: Shows each commit in a compact format with an abbreviated object name and commit subject.
- -5 = --max-count=5 (maximum count): Limits the output to five commits.

------------------------------------------------------------
# git log --graph --oneline --decorate --all

Explanation:
Displays the commit history as a compact graph and includes branch and tag names from all refs.

Options:
- --graph = graph display: Draws an ASCII representation of the branch and merge history.
- --oneline = one-line format: Shows each commit in a compact one-line format.
- --decorate = decorate refs: Shows reference names such as branches and tags next to commits.
- --all = all refs: Shows commits reachable from all refs instead of only the current branch.
