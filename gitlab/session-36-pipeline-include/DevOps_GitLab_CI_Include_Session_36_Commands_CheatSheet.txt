# tree -a .gitlab

Explanation:
Displays the directory tree starting from .gitlab, including hidden files and directories.

Options:
- -a = --all (all): Includes hidden files and directories in the output.

------------------------------------------------------------
# find .gitlab -type f -o -type d

Explanation:
Searches under .gitlab and matches both regular files and directories.

Options:
- -type f = file type test: Matches regular files.
- -o = logical OR: Matches when either the expression on the left or the expression on the right is true.
- -type d = directory type test: Matches directories.
