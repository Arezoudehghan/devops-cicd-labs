- 1 = non-zero exit status: Causes the shell script and CI job to report failure.

# sudo ss -lntp | grep 9252

Explanation:
Lists listening TCP sockets numerically with process information, then filters the output for port `9252`.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket when permissions allow.
- | = pipe operator: Sends the output of `ss` to `grep 9252`.
