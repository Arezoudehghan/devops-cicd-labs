Options:

# tar -czf dist/application.tar.gz app/

Explanation:
Creates a gzip-compressed tar archive named dist/application.tar.gz from the app/ directory.

Options:
- -c = --create (create): Create a new archive.
- -z = --gzip (gzip): Compress the archive with gzip.
- -f = --file (file): Use dist/application.tar.gz as the archive file name.
