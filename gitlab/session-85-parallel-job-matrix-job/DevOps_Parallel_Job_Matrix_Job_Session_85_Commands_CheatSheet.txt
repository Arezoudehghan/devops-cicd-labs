# docker run --rm \
        -v "$CI_PROJECT_DIR:/app" \
        -w /app \
        python:${PYTHON_VERSION}-slim \
        sh -c "pip install -r requirements.txt && pytest"

Explanation:
Runs the project tests inside a temporary Python container. It mounts the GitLab project at /app, installs dependencies from requirements.txt, and runs pytest only if installation succeeds.

Options:
- --rm = automatically remove the container when it exits: Deletes the stopped container after the command finishes.
- -v = --volume (volume): Mounts CI_PROJECT_DIR from the host at /app inside the container.
- -w = --workdir (working directory): Sets /app as the working directory inside the container.
- -c = command string: Tells sh to execute the following quoted command string.
- -r = --requirement (requirement file): Tells pip install to read dependencies from requirements.txt.
- && = AND operator: Runs pytest only if pip install completes successfully.
- \ = line continuation: Continues the same shell command on the next line.

# docker run --rm \
        -e APP_ENV="$APP_ENV" \
        -v "$CI_PROJECT_DIR:/app" \
        -w /app \
        python:${PYTHON_VERSION}-slim \
        sh -c "pip install -r requirements.txt && pytest"

Explanation:
Runs the project tests inside a temporary Python container while passing APP_ENV into the container. It mounts the project at /app, installs dependencies, and runs pytest only if installation succeeds.

Options:
- --rm = automatically remove the container when it exits: Deletes the stopped container after the command finishes.
- -e = --env (environment): Sets APP_ENV inside the container to the current APP_ENV value.
- -v = --volume (volume): Mounts CI_PROJECT_DIR from the host at /app inside the container.
- -w = --workdir (working directory): Sets /app as the working directory inside the container.
- -c = command string: Tells sh to execute the following quoted command string.
- -r = --requirement (requirement file): Tells pip install to read dependencies from requirements.txt.
- && = AND operator: Runs pytest only if pip install completes successfully.
- \ = line continuation: Continues the same shell command on the next line.
