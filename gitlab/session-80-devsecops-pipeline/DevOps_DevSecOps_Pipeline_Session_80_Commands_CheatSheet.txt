# ssh deploy@192.168.94.91 "
  docker pull '$IMAGE_NAME:$IMAGE_TAG' &&
  (docker stop devsecops-app 2>/dev/null || true) &&
  (docker rm devsecops-app 2>/dev/null || true) &&
  docker run -d \
    --name devsecops-app \
    --restart unless-stopped \
    -p 8088:5000 \
    '$IMAGE_NAME:$IMAGE_TAG'
"

Explanation:
Technical correction: The original command could continue after a failed docker pull because of the ungrouped && and || chain. The corrected command requires a successful image pull, ignores only missing old-container stop or remove errors, and then starts the new container.

Options:
- && = logical AND operator: Runs the next command only when the previous command succeeds.
- || = logical OR operator: Runs true only when the preceding stop or remove command fails.
- (...) = command grouping: Keeps each optional stop or remove operation together with its error handling.
- 2>/dev/null = standard error redirection: Sends file descriptor 2, stderr, to /dev/null.
- true = success command: Returns exit status 0 so an absent old container does not stop deployment.
- -d = --detach: Runs the new container in the background.
- --name = container name: Sets the container name to devsecops-app.
- --restart = restart policy: Uses unless-stopped so Docker restarts the container unless it was explicitly stopped.
- -p = --publish: Maps host port 8088 to container port 5000.
- \ = line continuation: Continues one shell command on the next physical line.
