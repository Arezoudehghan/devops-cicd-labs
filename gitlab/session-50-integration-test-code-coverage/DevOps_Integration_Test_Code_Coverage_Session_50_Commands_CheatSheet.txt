# pytest tests --cov=app --cov-report=term-missing

Explanation:
Runs all tests under tests, measures coverage for the app module, and prints missing lines in the terminal coverage report.

Options:
- --cov=app = coverage source: Measures test coverage for the app module.
- --cov-report=term-missing = coverage report type: Prints a terminal report that also lists missing line numbers.
------------------------------------------------------------

------------------------------------------------------------
# pytest tests --cov=app --cov-report=term-missing --cov-fail-under=80

Explanation:
Runs all tests, measures coverage for app, shows missing lines, and fails the test command if total coverage is below 80 percent.

Options:
- --cov=app = coverage source: Measures test coverage for the app module.
- --cov-report=term-missing = coverage report type: Prints a terminal report that also lists missing line numbers.
- --cov-fail-under=80 = minimum coverage threshold: Returns a failing exit status when total coverage is lower than 80 percent.
------------------------------------------------------------

# pytest tests -v --cov=app --cov-report=term-missing --cov-report=xml:reports/coverage.xml --junitxml=reports/all-tests.xml --cov-fail-under=80

Explanation:
Runs all tests with verbose output, measures coverage for app, creates terminal and XML coverage reports, creates a JUnit test report, and fails if coverage is below 80 percent.

Options:
- -v = --verbose (verbose): Increases pytest output verbosity.
- --cov=app = coverage source: Measures test coverage for the app module.
- --cov-report=term-missing = coverage report type: Prints a terminal coverage report that also lists missing line numbers.
- --cov-report=xml:reports/coverage.xml = XML coverage report and output path: Generates an XML coverage report and writes it to reports/coverage.xml.
- --junitxml=reports/all-tests.xml = JUnit XML output path: Writes the JUnit test report to reports/all-tests.xml; pytest also documents --junit-xml as an alias.
- --cov-fail-under=80 = minimum coverage threshold: Returns a failing exit status when total coverage is lower than 80 percent.
