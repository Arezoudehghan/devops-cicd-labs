# sudo ss -lntp | grep ':8085'

Explanation:
Lists listening TCP sockets with numeric addresses and process information, then keeps only lines that contain port 8085.

Options:
- -l = --listening (listening): Show only listening sockets.
- -n = --numeric (numeric): Do not resolve service names; show numeric ports and addresses.
- -t = --tcp (TCP): Show TCP sockets.
- -p = --processes (processes): Show the process using each socket.
- | = pipe operator: Send the output of `ss` to `grep` as input.

# sudo cat /etc/docker/daemon.json 2>/dev/null || true

Explanation:
Displays the current Docker daemon configuration if the file exists. Errors are hidden, and the command sequence still returns success if `cat` fails.

Options:
- 2>/dev/null = stderr redirection: Send file descriptor 2, standard error, to `/dev/null`.
- || = OR operator: Run the command on the right only if the command on the left fails.

# sudo cp /etc/docker/daemon.json /etc/docker/daemon.json.bak-$(date +%F-%H%M%S)

Explanation:
Copies the Docker daemon configuration to a timestamped backup file.

Options:
- $(...) = command substitution: Run `date` and insert its output into the destination filename.
- +%F-%H%M%S = date format argument: `%F` is the full date, `%H` is the hour, `%M` is the minute, and `%S` is the second.
