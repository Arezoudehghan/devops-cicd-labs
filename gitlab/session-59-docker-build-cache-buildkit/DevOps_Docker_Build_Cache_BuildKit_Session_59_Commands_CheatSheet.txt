# RUN apt-get update \
    && apt-get install -y --no-install-recommends gcc \
    && rm -rf /var/lib/apt/lists/*

Explanation:
Updates APT package metadata, installs gcc without recommended packages, and then removes cached APT list files in the same Docker build step.

Options:
- && = shell AND operator: Runs the next command only if the previous command succeeds.
- -y = --assume-yes (assume yes): Automatically answers yes to APT confirmation prompts.
- --no-install-recommends = do not install recommended packages: Prevents APT from installing packages marked only as recommended.
- -r = --recursive (recursive): Makes rm remove directories and their contents recursively.
- -f = --force (force): Makes rm ignore nonexistent files and suppress confirmation prompts.
