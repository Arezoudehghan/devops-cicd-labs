# mkdir -p dist

Explanation:
Creates the dist directory and does not fail if the directory already exists.

Options:
- -p = --parents: Create parent directories as needed and do not report an error if the directory already exists.
------------------------------------------------------------

------------------------------------------------------------
# echo "Application build from pipeline $CI_PIPELINE_ID" > dist/app.txt

Explanation:
Writes a build message containing the current pipeline ID into dist/app.txt. The file is created if it does not exist.

Options:
- > = output redirection: Redirect standard output to dist/app.txt and overwrite the file if it already exists.

------------------------------------------------------------
# test -f dist/app.txt

Explanation:
Checks whether dist/app.txt exists and is a regular file. The command returns a successful exit status when the condition is true.

Options:
- -f = regular-file test operator: Return true when the specified path exists and is a regular file.
------------------------------------------------------------

------------------------------------------------------------
# grep -q "Application build" dist/app.txt

Explanation:
Checks whether dist/app.txt contains the text "Application build" without printing matching lines.

Options:
- -q = --quiet: Suppress normal output and use only the command exit status to indicate whether a match was found.
