# CHANGED_FILES=$(git diff --name-only "$CI_COMMIT_BEFORE_SHA" "$CI_COMMIT_SHA" || true)

Explanation:
Stores the names of files changed between the previous and current GitLab commits in CHANGED_FILES. If git diff fails, true makes the command substitution succeed.

Options:
- $() = command substitution: Runs the enclosed command and substitutes its output into CHANGED_FILES.
- --name-only = show only names of changed files: Suppresses the normal patch and prints changed paths.
- "$CI_COMMIT_BEFORE_SHA" = first revision argument: Uses the previous commit SHA supplied by GitLab CI.
- "$CI_COMMIT_SHA" = second revision argument: Uses the current commit SHA supplied by GitLab CI.
- || = OR operator: Runs the command on the right only if the command on the left fails.
