# grep -qx "healthy" app/health.txt

Explanation:
Checks silently whether app/health.txt contains a line that is exactly healthy. It returns success only when an exact matching line is found.

Options:
- -q = --quiet (quiet): Suppress normal output and use only the exit status.
- -x = --line-regexp (line regexp): Match only when the entire line matches the pattern.

# git log --graph --oneline --decorate --all

Explanation:
Shows commit history for all refs in a compact graph view with branch and tag decorations.

Options:
- --graph = graph display: Draw an ASCII graph of the branch and merge history.
- --oneline = one-line log format: Show each commit in a compact single-line format.
- --decorate = decorate refs: Show reference names such as branches and tags next to commits.
- --all = all refs: Show commits reachable from all refs.
