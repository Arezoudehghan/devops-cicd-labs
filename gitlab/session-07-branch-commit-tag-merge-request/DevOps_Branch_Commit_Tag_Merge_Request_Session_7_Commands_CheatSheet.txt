# git log --oneline --graph --decorate --all

Explanation:
Shows a compact visual history of commits, branches, tags, and other references.

Options:
- --oneline = compact one-line format: Shows each commit as an abbreviated hash plus its subject.
- --graph = text graph: Draws the branch and merge structure using ASCII graph characters.
- --decorate = show reference names: Displays names such as branches, tags, and HEAD beside commits.
- --all = all references: Includes commits reachable from all refs instead of only the current history.
