# docker build -t myapp:1.0 .

Explanation:
Builds a Docker image from the Dockerfile in the current directory and tags it as myapp:1.0.

Options:
- -t = --tag (tag): Assigns the name and tag myapp:1.0 to the built image.
- . = current directory: Uses the current directory as the build context.

# docker run --rm \
  -v /:/host \
  alpine \
  cat /host/etc/shadow

Explanation:
Starts an Alpine container, mounts the host root filesystem at /host, and runs cat on /host/etc/shadow inside the container.

Options:
- --rm = remove after exit: Automatically removes the container when it stops.
- -v = --volume (volume): Mounts the host path / at the container path /host.
- /:/host = volume mapping: Uses / as the source path and /host as the destination path.
- \\ = shell line continuation: Continues the same command on the next line.

# buildah build \
  --layers \
  --cache-from registry.example.com/myapp/cache \
  --cache-to registry.example.com/myapp/cache \
  -t myapp:1.0 .

Explanation:
Builds the image with reusable layers, reads cache from the specified registry location, writes cache back to that location, and tags the result as myapp:1.0.

Options:
- --layers = layer caching: Caches intermediate image layers during the build.
- --cache-from registry.example.com/myapp/cache = cache source: Uses the specified registry repository as an external build-cache source.
- --cache-to registry.example.com/myapp/cache = cache destination: Stores reusable build cache in the specified registry repository.
- -t = --tag (tag): Assigns the name and tag myapp:1.0 to the built image.
- . = current directory: Uses the current directory as the build context.
- \\ = shell line continuation: Continues the same command on the next line.

# docker build -t "${IMAGE_NAME}:${IMAGE_TAG}" .

Explanation:
Builds a Docker image from the current directory and creates its name and tag from GitLab CI variables.

Options:
- -t = --tag (tag): Assigns the expanded ${IMAGE_NAME}:${IMAGE_TAG} value as the image name and tag.
- ${IMAGE_NAME} = shell variable expansion: Expands to the value stored in IMAGE_NAME.
- ${IMAGE_TAG} = shell variable expansion: Expands to the value stored in IMAGE_TAG.
- . = current directory: Uses the current directory as the build context.
------------------------------------------------------------

------------------------------------------------------------
