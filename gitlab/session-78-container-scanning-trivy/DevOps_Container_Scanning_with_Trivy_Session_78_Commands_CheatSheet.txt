# wget -qO - https://aquasecurity.github.io/trivy-repo/deb/public.key \
| gpg --dearmor \
| sudo tee /usr/share/keyrings/trivy.gpg > /dev/null

Explanation:
Downloads the Trivy repository public key, converts it to GPG keyring format, and writes it to `/usr/share/keyrings/trivy.gpg`.

Options:
- -q = --quiet (quiet): Suppresses normal `wget` output.
- -O - = --output-document=- (output document): Sends the downloaded key to standard output instead of saving it as a normal file.
- \ = shell line continuation: Continues the same command on the next line.
- | = pipe operator: Sends the output of the command on the left to the command on the right.
- --dearmor = dearmor: Converts ASCII-armored OpenPGP data to binary OpenPGP format.
- > /dev/null = output redirection: Discards the normal output produced by `tee`.
------------------------------------------------------------
