# sudo cp -a /etc/gitlab-runner/config.toml /etc/gitlab-runner/config.toml.bak-session21-$(date +%F-%H%M%S)

Explanation:
Creates an archive-style backup copy of config.toml with the current date and time in the backup filename.

Options:
- -a = --archive (archive): Preserves file attributes as much as possible while copying.
- $(...) = command substitution: Runs date +%F-%H%M%S and inserts its output into the destination filename.
- +%F-%H%M%S = date format argument: Formats the timestamp as YYYY-MM-DD-HHMMSS.

# ps -u gitlab-runner -o pid,ppid,etime,%cpu,%mem,cmd

Explanation:
Shows processes owned by the gitlab-runner user with selected process columns.

Options:
- -u = --user (user): Selects processes by effective user; here the user is gitlab-runner.
- -o = --format (format): Selects the output columns; here they are PID, parent PID, elapsed time, CPU percentage, memory percentage, and command.
------------------------------------------------------------
# watch -n 1 'ps -u gitlab-runner -o pid,ppid,etime,%cpu,%mem,cmd'

Explanation:
Runs the ps command repeatedly so GitLab Runner processes can be monitored live.

Options:
- -n = --interval (interval): Sets the refresh interval; here it is 1 second.
- Inner -u = --user (user): Selects processes owned by the gitlab-runner effective user.
- Inner -o = --format (format): Selects PID, parent PID, elapsed time, CPU percentage, memory percentage, and command columns.
