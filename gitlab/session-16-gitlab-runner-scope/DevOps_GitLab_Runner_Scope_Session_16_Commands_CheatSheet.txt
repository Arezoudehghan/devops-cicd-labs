# gitlab-runner --version

Explanation:
Displays the installed GitLab Runner version.

Options:
- --version = display version information: Prints the GitLab Runner version and exits.

# sudo systemctl status gitlab-runner --no-pager

Explanation:
Shows the current systemd status of the GitLab Runner service with elevated privileges.

Options:
- --no-pager = disable pager output: Prints the status directly instead of opening it in a pager such as less.

# gitlab-runner unregister --name "<RUNNER_NAME>"

Explanation:
Technical correction: The lesson showed `gitlab-runner unregister` without a runner selector. This corrected form unregisters the runner whose configured name matches `<RUNNER_NAME>`.

Options:
- --name "<RUNNER_NAME>" = runner name selector: Selects the registered runner to unregister by its configured name.

# sudo gitlab-runner register

Explanation:
Starts the interactive GitLab Runner registration process with elevated privileges.
------------------------------------------------------------
# sudo gitlab-runner register \
  --url "http://192.168.94.90" \
  --token "<INSTANCE_RUNNER_AUTH_TOKEN>"

Explanation:
Registers the Instance Runner with the GitLab server at `http://192.168.94.90` by using its runner authentication token.

Options:
- \ = shell line continuation: Continues the same command on the next line.
- --url "http://192.168.94.90" = GitLab instance URL: Specifies the GitLab server that the runner registers with.
- --token "<INSTANCE_RUNNER_AUTH_TOKEN>" = runner authentication token: Supplies the authentication token created for the Instance Runner.
------------------------------------------------------------
