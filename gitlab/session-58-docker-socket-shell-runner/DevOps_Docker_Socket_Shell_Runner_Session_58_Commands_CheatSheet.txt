------------------------------------------------------------
# docker ps

Explanation:
Lists the currently running Docker containers.
------------------------------------------------------------
# docker build -t myapp:1.0 .

Explanation:
Builds a Docker image from the Dockerfile in the current directory and tags it as myapp:1.0.

Options:
- -t = --tag: Assigns the name and tag myapp:1.0 to the built image.
- . = current directory build context: Sends the current directory as the Docker build context.
------------------------------------------------------------
# ls -l /var/run/docker.sock

Explanation:
Shows detailed file information for the Docker Unix socket.

Options:
- -l = long listing format: Displays permissions, owner, group, size, date, and file name.
------------------------------------------------------------
# stat -c '%A %a %U %G %n' /var/run/docker.sock

Explanation:
Displays selected permission and ownership information for the Docker socket.

Options:
- -c = --format=FORMAT: Uses the supplied format string instead of the default stat output.
- '%A %a %U %G %n' = format value: %A shows symbolic permissions, %a shows octal permissions, %U shows the owner name, %G shows the group name, and %n shows the file name.

# docker build -t "${CI_PROJECT_NAME}:${CI_COMMIT_SHORT_SHA}" .

# docker run --rm -v /:/host:ro alpine cat /host/etc/os-release

Explanation:
Starts a temporary Alpine container, mounts the host root filesystem read-only at /host, and prints the host operating-system release file.

Options:
- --rm = automatically remove the container: Deletes the container when its process exits.
- -v = --volume: Creates the bind mount specified by /:/host:ro.
- /:/host:ro = volume value: Mounts host / at container /host and uses ro for read-only access.
- alpine = image argument: Uses the Alpine Linux image for the container.
- cat /host/etc/os-release = container command: Prints the mounted host /etc/os-release file.
------------------------------------------------------------
