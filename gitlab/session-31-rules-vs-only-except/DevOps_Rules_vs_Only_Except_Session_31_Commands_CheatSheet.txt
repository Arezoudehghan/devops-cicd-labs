# docker build -t myapp .

Explanation:
Builds a Docker image from the Dockerfile and build context in the current directory, and names the image `myapp`.

Options:
- -t = --tag (tag): Sets the image name and optional tag; here the value is `myapp`.
- . = current directory build context: Uses the current directory as the files and Dockerfile context for the build.
