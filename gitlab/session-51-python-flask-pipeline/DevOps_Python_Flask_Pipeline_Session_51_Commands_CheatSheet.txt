# HEALTH_PORT="$($VENV_DIR/bin/python -c 'import socket; s=socket.socket(); s.bind(("127.0.0.1", 0)); print(s.getsockname()[1]); s.close()')"

Explanation:
Finds an available local TCP port with Python and stores it in HEALTH_PORT.

Options:
- $() = command substitution: Runs the enclosed Python command and stores its stdout in the variable.
- $VENV_DIR = shell variable: Expands to the virtual-environment path.
- -c = command string: Executes the provided Python code string.
- 127.0.0.1 = loopback address: Limits the temporary socket to the local host.
- 0 = dynamic port request: Lets the operating system choose an available port.

# $VENV_DIR/bin/gunicorn \
  --chdir release \
  --bind "127.0.0.1:${HEALTH_PORT}" \
  app:app > gunicorn.log 2>&1 &

Explanation:
Starts Gunicorn from the release directory on the dynamically selected loopback port, sends logs to gunicorn.log, and runs it in the background.

Options:
- $VENV_DIR = shell variable: Expands to the virtual-environment path.
- --chdir release = change directory: Changes Gunicorn's working directory to release before loading the app.
- --bind "127.0.0.1:${HEALTH_PORT}" = bind address: Listens only on loopback at the selected health-check port.
- > = stdout redirection: Writes standard output to gunicorn.log.
- 2>&1 = stderr redirection: Sends file descriptor 2, stderr, to the same destination as stdout.
- & = background operator: Starts Gunicorn asynchronously so the script can continue.

# trap 'kill "$APP_PID" 2>/dev/null || true' EXIT

Explanation:
Registers cleanup code that tries to stop the background application whenever the shell exits.

Options:
- 2>/dev/null = stderr redirection: Discards error output from kill.
- || = logical OR operator: Runs true only if kill returns a nonzero status.
- true = success command: Returns exit status 0 so cleanup does not make the job fail.
- EXIT = Bash trap condition: Runs the registered action when the shell is exiting.

# for attempt in $(seq 1 20); do
  if curl --fail --silent \
    "http://127.0.0.1:${HEALTH_PORT}/health" > health.json; then

    HEALTH_OK=1
    break
  fi

  sleep 1
done

Explanation:
Retries the application health endpoint up to 20 times, saving a successful response to health.json and stopping the loop when the check passes.

Options:
- $() = command substitution: Runs seq 1 20 and inserts its output into the for loop.
- --fail = fail on HTTP errors: Makes curl return a failure status for HTTP response codes 400 and above.
- --silent = silent mode: Hides curl's progress meter and normal informational output.
- > = stdout redirection: Replaces health.json with the HTTP response body on each attempt.
- ${HEALTH_PORT} = shell variable expansion: Inserts the dynamically selected port into the URL.
- break = loop control: Stops the loop after the first successful health check.
- sleep 1 = delay: Waits one second before the next retry.
