# RUN python -m pip install \
    --no-cache-dir \
    --disable-pip-version-check \
    --trusted-host pypi.org \
    --trusted-host files.pythonhosted.org \
    -r requirements.txt

Explanation:
Runs pip through Python and installs the packages listed in requirements.txt during the image build.

Options:
- -m = run library module as a script: Runs the pip module through Python.
- --no-cache-dir = disable the pip cache: Prevents pip from storing downloaded package cache files.
- --disable-pip-version-check = disable the pip version check: Stops pip from checking whether a newer pip version is available.
- --trusted-host pypi.org = trusted host: Marks pypi.org as trusted for this pip operation.
- --trusted-host files.pythonhosted.org = trusted host: Marks files.pythonhosted.org as trusted for this pip operation.
- -r = --requirement (requirement): Installs dependencies from requirements.txt.
