# cat > build-meta/build-info.txt <<EOF
PROJECT=${CI_PROJECT_NAME}
PIPELINE_ID=${CI_PIPELINE_ID}
JOB_ID=${CI_JOB_ID}
COMMIT_SHA=${CI_COMMIT_SHA}
COMMIT_SHORT_SHA=${CI_COMMIT_SHORT_SHA}
REF=${CI_COMMIT_REF_NAME}
BUILT_AT=$(date -u +"%Y-%m-%dT%H:%M:%SZ")
EOF

Explanation:
Writes build metadata into build-meta/build-info.txt using a shell here-document. The BUILT_AT value is generated in UTC by the date command.

Options:
- > = output redirection: Creates or truncates build-meta/build-info.txt and writes the command output into it.
- <<EOF = here-document operator: Sends all following lines up to EOF to cat as standard input.
- $(...) = command substitution: Runs date -u +"%Y-%m-%dT%H:%M:%SZ" and inserts its output into BUILT_AT.
- -u = --utc (UTC): Makes date print the time in Coordinated Universal Time.
- +"%Y-%m-%dT%H:%M:%SZ" = date format argument: Produces a timestamp such as 2026-08-20T22:30:14Z.

# FILE="dist/${CI_PROJECT_NAME}-${CI_COMMIT_SHORT_SHA}.tar.gz"
FILE_NAME=$(basename "$FILE")

curl --fail-with-body --location \
  --header "JOB-TOKEN: ${CI_JOB_TOKEN}" \
  --upload-file "$FILE" \
  "${CI_API_V4_URL}/projects/${CI_PROJECT_ID}/packages/generic/${CI_PROJECT_NAME}/${CI_COMMIT_TAG}/${FILE_NAME}"

Explanation:
Sets the release file path, extracts its base file name, and uploads the artifact to the GitLab Generic Package Registry with the CI job token.

Options:
- $(...) = command substitution: Runs basename "$FILE" and stores its output in FILE_NAME.
- --fail-with-body = fail with response body: Makes curl return an error for HTTP response codes 400 or greater while still printing the response body.
- --location = follow redirects: Makes curl follow HTTP redirects.
- --header "JOB-TOKEN: ${CI_JOB_TOKEN}" = HTTP header: Sends the GitLab CI job token in the JOB-TOKEN request header.
- --upload-file "$FILE" = upload file: Uploads the file stored in the FILE variable.
- \ = shell line continuation: Continues the same curl command on the next line.
