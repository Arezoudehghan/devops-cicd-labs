# docker run -d \
  --name cicd-app \
  -p 8088:5000 \
  --restart unless-stopped \
  192.168.94.90:8085/cicd-app:a83fc21

Explanation:
Starts the specified image as a new container named cicd-app, publishes port 8088 to container port 5000, and configures an automatic restart policy.

Options:
- -d = --detach (detach): Run the container in the background.
- --name = container name: Set the container name to cicd-app.
- -p = --publish (publish): Map host port 8088 to container port 5000.
- --restart = restart policy: Apply the unless-stopped restart policy.
- unless-stopped = restart policy value: Restart the container automatically unless it was explicitly stopped.
- \\ = shell line continuation: Continue the same command on the next line.

# ssh -i "$SSH_PRIVATE_KEY" "$DEPLOY_USER@$DEPLOY_HOST" "
  set -euo pipefail

  cd '$DEPLOY_PATH'

  if [ -f .env ]; then
    cp .env .env.previous
  fi

  cat > .env <<EOF
NEXUS_REGISTRY=$NEXUS_REGISTRY
IMAGE_NAME=$IMAGE_NAME
IMAGE_TAG=$CI_COMMIT_SHORT_SHA
APP_PORT=$APP_PORT
EOF

  docker compose config -q

  docker compose pull

  docker compose up \
    -d \
    --remove-orphans \
    --wait \
    --wait-timeout 60

  docker compose ps

  docker logout '$NEXUS_REGISTRY'
"

Explanation:
Connects to the deployment server and runs the full remote deployment sequence: fail-fast shell settings, deployment-directory selection, previous environment backup, new environment-file creation, Compose validation, image pull, service update, status check, and registry logout.

Options:
- -i = identity_file: Use SSH_PRIVATE_KEY as the SSH private key file.
- -e = shell errexit option: Exit when a command fails.
- -u = shell nounset option: Treat an unset variable as an error.
- -o pipefail = shell pipefail option: Make a pipeline fail if any command in the pipeline fails.
- -f = file test operator: In [ -f .env ], return true when .env exists and is a regular file.
- > = shell output redirection: Replace .env with the output written by cat.
- <<EOF = here-document operator: Feed the following lines to cat until the terminating EOF line.
- -q = --quiet (quiet): Validate the Compose configuration without printing it.
- -d = --detach (detach): Run the Compose services in the background.
- --remove-orphans = remove orphan containers: Remove containers for services no longer defined in the Compose file.
- --wait = wait for services: Wait until the services are running or healthy.
- --wait-timeout 60 = wait timeout: Limit the wait period to 60 seconds.
