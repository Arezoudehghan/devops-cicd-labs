# trivy fs --severity HIGH,CRITICAL --exit-code 1 .

Explanation:
Scans the current filesystem directory with Trivy and returns exit code 1 when matching vulnerabilities are found.

Options:
- fs = filesystem scan subcommand: Scans files and dependencies from the specified filesystem path.
- --severity HIGH,CRITICAL = severity filter: Reports findings with HIGH or CRITICAL severity.
- --exit-code 1 = exit code on findings: Makes Trivy return status code 1 when matching findings are detected.
- . = scan target: Scans the current directory.

# curl --request POST \
  --form "token=$GITLAB_TRIGGER_TOKEN" \
  --form "ref=main" \
  "https://gitlab.example.com/api/v4/projects/PROJECT_ID/trigger/pipeline"

Explanation:
Sends an HTTP POST request to the GitLab pipeline trigger API for the `main` branch using the trigger token stored in `$GITLAB_TRIGGER_TOKEN`.

Options:
- --request POST = request method: Explicitly uses the HTTP POST method.
- --form "token=$GITLAB_TRIGGER_TOKEN" = form field: Sends the GitLab trigger token as multipart form data.
- --form "ref=main" = form field: Requests a pipeline for the `main` branch.
- \ = shell line continuation: Continues the same command on the next line.
------------------------------------------------------------
# curl --request POST \
  --form "token=$GITLAB_TRIGGER_TOKEN" \
  --form "ref=main" \
  --form "variables[DEPLOY_ENV]=staging" \
  --form "variables[APP_VERSION]=1.4.2" \
  "https://gitlab.example.com/api/v4/projects/PROJECT_ID/trigger/pipeline"

Explanation:
Triggers the GitLab pipeline for `main` and passes deployment environment and application version variables to the new pipeline.

Options:
- --request POST = request method: Explicitly uses the HTTP POST method.
- --form "token=$GITLAB_TRIGGER_TOKEN" = form field: Sends the GitLab trigger token as multipart form data.
- --form "ref=main" = form field: Requests a pipeline for the `main` branch.
- --form "variables[DEPLOY_ENV]=staging" = form field: Sets the pipeline variable `DEPLOY_ENV` to `staging`.
- --form "variables[APP_VERSION]=1.4.2" = form field: Sets the pipeline variable `APP_VERSION` to `1.4.2`.
- \ = shell line continuation: Continues the same command on the next line.
