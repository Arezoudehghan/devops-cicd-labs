# FROM python:3.12-slim

WORKDIR /app

COPY . .

RUN pip install --no-cache-dir -r requirements.txt

USER root

CMD ["python", "app.py"]

Explanation:
Builds a Python 3.12 slim image, copies the application into /app, installs dependencies, and runs the application as root.

Options:
- --no-cache-dir = disable pip cache: Prevents pip from storing downloaded package files in its cache.
- -r = --requirement (requirement file): Installs packages listed in requirements.txt.

# FROM python:3.12-slim

WORKDIR /app

RUN groupadd --system appgroup && \
    useradd --system --gid appgroup appuser

COPY --chown=appuser:appgroup . .

RUN pip install --no-cache-dir -r requirements.txt

USER appuser

CMD ["python", "app.py"]

Explanation:
Builds the application image with a dedicated non-root user and gives copied files to that user before starting the application.

Options:
- --system = system account/group mode: Creates a system group with groupadd and a system user with useradd.
- --gid appgroup = group ID or group name for the new user: Assigns appuser to appgroup.
- --chown=appuser:appgroup = set ownership during COPY: Copies files into the image with appuser as owner and appgroup as group.
- --no-cache-dir = disable pip cache: Prevents pip from storing downloaded package files in its cache.
- -r = --requirement (requirement file): Installs packages listed in requirements.txt.
- && = shell AND operator: Runs useradd only if groupadd succeeds.
- \ = line continuation: Continues the shell command on the next line.

# apiVersion: apps/v1
kind: Deployment

metadata:
  name: myapp

spec:
  replicas: 1

  selector:
    matchLabels:
      app: myapp

  template:
    metadata:
      labels:
        app: myapp

    spec:
      containers:
        - name: myapp
          image: myapp:1.0

          securityContext:
            privileged: false
            runAsNonRoot: true
            runAsUser: 10001
            allowPrivilegeEscalation: false
            readOnlyRootFilesystem: true

            capabilities:
              drop:
                - ALL

Explanation:
Defines a Kubernetes Deployment with a hardened security context that disables privileged mode and privilege escalation, requires a non-root user, uses a read-only root filesystem, and drops all Linux capabilities.

- --severity HIGH,CRITICAL = severity filter: Limits considered findings to HIGH and CRITICAL severities.
