------------------------------------------------------------
# docker build -t myapp:$CI_COMMIT_SHA .

Explanation:
Builds a Docker image from the current directory and tags it with the full GitLab commit SHA stored in CI_COMMIT_SHA.

Options:
- -t = --tag (tag): Assigns the name and tag myapp:$CI_COMMIT_SHA to the built image.
------------------------------------------------------------
# docker build -t myapp:$CI_COMMIT_SHORT_SHA .

Explanation:
Builds a Docker image from the current directory and tags it with the short GitLab commit SHA stored in CI_COMMIT_SHORT_SHA.

Options:
- -t = --tag (tag): Assigns the name and tag myapp:$CI_COMMIT_SHORT_SHA to the built image.
------------------------------------------------------------
# docker build -t "$IMAGE_NAME:$CI_COMMIT_SHA" .

Explanation:
Builds a Docker image from the current directory and tags it with IMAGE_NAME plus the full Git commit SHA.

Options:
- -t = --tag (tag): Assigns "$IMAGE_NAME:$CI_COMMIT_SHA" as the image name and tag.
------------------------------------------------------------
# docker tag "$IMAGE_NAME:$CI_COMMIT_SHA" "$IMAGE_NAME:$CI_COMMIT_SHORT_SHA"

Explanation:
Creates a second tag using the short commit SHA for the same image already tagged with the full commit SHA.
------------------------------------------------------------
# docker tag "$IMAGE_NAME:$CI_COMMIT_SHA" "$IMAGE_NAME:$CI_COMMIT_REF_SLUG"

Explanation:
Creates a branch-safe tag from CI_COMMIT_REF_SLUG for the same image already tagged with the full commit SHA.

# echo "$NEXUS_PASSWORD" | docker login "$NEXUS_REGISTRY" -u "$NEXUS_USER" --password-stdin

Explanation:
Sends the Nexus password through standard input and logs Docker in to the registry using the configured username.

Options:
- | = pipe operator: Sends the output of echo to the standard input of docker login.
- -u = --username (username): Uses "$NEXUS_USER" as the registry username.
- --password-stdin = read password from standard input: Reads the password from the pipe instead of placing it directly on the command line.

# docker build \
  --build-arg HTTP_PROXY="$HTTP_PROXY" \
  --build-arg HTTPS_PROXY="$HTTPS_PROXY" \
  --build-arg NO_PROXY="$NO_PROXY" \
  -t "$IMAGE_NAME:$CI_COMMIT_SHA" \
  .

Explanation:
Builds the Docker image from the current directory, passes proxy-related build arguments, and tags the image with the full commit SHA.

Options:
- --build-arg HTTP_PROXY="$HTTP_PROXY" = --build-arg: Passes the HTTP_PROXY build argument and its value into the Docker build.
- --build-arg HTTPS_PROXY="$HTTPS_PROXY" = --build-arg: Passes the HTTPS_PROXY build argument and its value into the Docker build.
- --build-arg NO_PROXY="$NO_PROXY" = --build-arg: Passes the NO_PROXY build argument and its value into the Docker build.
- -t = --tag (tag): Assigns "$IMAGE_NAME:$CI_COMMIT_SHA" as the image name and tag.
- \ = shell line continuation: Continues the same command on the next line.
