# ssh "${DEPLOY_USER}@${DEPLOY_HOST}" "
  set -e

  mkdir -p /opt/cicd-app

  docker inspect \
    -f '{{.Config.Image}}' \
    ${APP_NAME} \
    > /opt/cicd-app/.previous_image \
    2>/dev/null || true

  docker pull '${IMAGE_REF}'

  docker rm -f ${APP_NAME} 2>/dev/null || true

  docker run -d \
    --name ${APP_NAME} \
    --restart unless-stopped \
    -p ${APP_PORT}:${CONTAINER_PORT} \
    -e APP_ENV=production \
    '${IMAGE_REF}'
"

Explanation:
Runs the deployment workflow on the remote host: saves the previous image, pulls the new image, removes the old container, and starts the new container.

Options:
- set -e = errexit shell option: Stops the remote shell when an unhandled command returns a non-zero status.
- mkdir -p: -p = --parents (parents), which creates missing parent directories and ignores an already existing directory.
- docker inspect -f: -f = --format (format), which prints only the selected Go-template value.
- > = stdout redirection: Writes standard output to /opt/cicd-app/.previous_image and replaces existing content.
- 2>/dev/null = stderr redirection: Sends file descriptor 2, standard error, to /dev/null.
- || = OR operator: Runs true only if the command before it fails.
- docker rm -f: -f = --force (force), which force-removes the container.
- docker run -d: -d = --detach (detach), which runs the container in the background.
- --name = container name: Assigns ${APP_NAME} as the container name.
- --restart = restart policy: Uses unless-stopped so Docker restarts the container unless it was explicitly stopped.
- -p = --publish (publish): Maps ${APP_PORT} on the host to ${CONTAINER_PORT} in the container.
- -e = --env (environment): Sets APP_ENV=production inside the container.

- || = OR operator: Runs true when curl fails so the loop can continue and inspect the result.
- exit 0 = success status: Ends the remote shell successfully.
- sleep 3 = delay value: Waits three seconds between attempts.
