# sudo usermod -aG docker gitlab-runner

Explanation:
Adds the gitlab-runner user to the docker supplementary group without removing its existing supplementary groups.

Options:
- -a = --append (append): Adds the user to the listed supplementary groups without removing existing supplementary group memberships.
- -G = --groups (groups): Specifies the supplementary group list; here the group is docker.
------------------------------------------------------------

------------------------------------------------------------
# sudo -u gitlab-runner -H docker info

Explanation:
Runs docker info as the gitlab-runner user and sets HOME to that user's home directory.

Options:
- -u = --user (user): Runs the command as the specified user, here gitlab-runner.
- -H = --set-home (set home): Sets the HOME environment variable to the target user's home directory.
