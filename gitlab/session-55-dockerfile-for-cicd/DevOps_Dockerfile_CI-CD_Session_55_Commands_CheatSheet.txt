# RUN groupadd --system app && \

# RUN groupadd --system --gid 10001 app && \
    useradd \
      --system \
      --uid 10001 \
      --gid app \
      --create-home \
      app

Explanation:
Creates the system group app with GID 10001, then creates the system user app with UID 10001, primary group app, and a home directory.

Options:
- groupadd --system = system group mode: Creates app as a system group.
- groupadd --gid 10001 = group ID: Sets the new app group's numeric GID to 10001.
- useradd --system = system user mode: Creates app as a system user.
- useradd --uid 10001 = user ID: Sets the new user's numeric UID to 10001.
- useradd --gid app = primary group: Sets the new user's primary group to app.
- useradd --create-home = create home directory: Creates a home directory for the new user.
- && = shell AND operator: Runs useradd only if groupadd succeeds.
- \ = shell line continuation: Continues the same shell command on the next line.
