# sudo gitlab-runner register \
  --non-interactive \
  --url "http://192.168.94.90" \
  --token "$RUNNER_TOKEN" \
  --executor "shell" \
  --description "dev-1-s15-shell"

Explanation:
Registers a GitLab Runner non-interactively with the GitLab instance using the supplied authentication token. It configures the Runner to use the Shell executor and assigns the description dev-1-s15-shell.

Options:
- --non-interactive = non-interactive mode: Performs registration without asking interactive questions.
- --url "http://192.168.94.90" = GitLab URL: Sets the GitLab instance URL used by the Runner.
- --token "$RUNNER_TOKEN" = authentication token: Uses the value stored in RUNNER_TOKEN to authenticate the Runner.
- --executor "shell" = executor: Configures the Runner to execute jobs with the Shell executor.
- --description "dev-1-s15-shell" = description: Sets the Runner configuration description to dev-1-s15-shell.

# sudo journalctl -u gitlab-runner -n 100 --no-pager

Explanation:
Displays the latest 100 journal entries for the gitlab-runner systemd service with elevated privileges.

Options:
- -u = --unit (unit): Filters journal entries to the gitlab-runner systemd unit.
- -n 100 = --lines=100 (lines): Limits the output to the latest 100 journal entries.
- --no-pager = no pager: Prints the journal output directly instead of opening it in a pager.
