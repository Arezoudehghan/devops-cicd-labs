# echo "BUILD START $(date '+%H:%M:%S')"

Explanation:
Prints the build start time. The date command is executed inside command substitution and its result is inserted into the message.

Options:
- $(...) = command substitution: Runs the enclosed command and inserts its output into the surrounding command.
- +%H:%M:%S = date format argument: %H is the 24-hour hour, %M is the minute, and %S is the second.

# sudo journalctl -u gitlab-runner -n 100 --no-pager

Explanation:
Shows the latest 100 journal entries for the GitLab Runner systemd unit without opening a pager.

Options:
- -u = --unit (unit): Filters messages for the specified systemd unit, here gitlab-runner.
- -n 100 = --lines=100 (lines): Shows the most recent 100 journal entries.
- --no-pager = no pager: Prints the output directly instead of sending it to a pager program.

# docker run --name test-app nginx

Explanation:
Starts a container from the nginx image and assigns the container the fixed name test-app.

Options:

------------------------------------------------------------

------------------------------------------------------------
# docker run --name "test-app-$CI_JOB_ID" nginx

Explanation:
Starts an nginx container with a job-specific name. CI_JOB_ID makes the container name unique for each GitLab CI/CD job.

Options:
- --name = container name: Assigns the specified name to the new container.
------------------------------------------------------------

------------------------------------------------------------
# docker run -p 8080:80 nginx

Explanation:
Starts an nginx container and publishes container port 80 on host port 8080.

Options:
- -p = --publish (publish): Publishes a container port to the host.
- 8080:80 = publish value: Maps host port 8080 to container port 80.
------------------------------------------------------------

------------------------------------------------------------
# echo "result" > "/tmp/result-$CI_JOB_ID.txt"

Explanation:
Writes the word result to a job-specific file in /tmp. The CI_JOB_ID variable gives each parallel job a different filename.

Options:
- > = output redirection: Writes standard output to the target file, replacing the file if it already exists.
