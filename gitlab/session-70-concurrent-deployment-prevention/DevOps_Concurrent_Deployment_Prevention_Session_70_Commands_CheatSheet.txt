# docker stop myapp || true

Explanation:
Stops the container named myapp. If the stop command fails, the shell runs true so the compound command still succeeds.

Options:
- || = shell logical OR operator: Runs the command on the right only if the command on the left fails.
------------------------------------------------------------

# docker run -d --name myapp -p 8088:8080 nexus:8085/myapp:$IMAGE_TAG

Explanation:
Starts a new container named myapp in the background from the image tagged by $IMAGE_TAG. It maps host port 8088 to container port 8080.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name myapp = name: Assigns the container name myapp.
- -p 8088:8080 = --publish 8088:8080 (publish): Maps host port 8088 to container port 8080.

# ssh deploy@192.168.94.91 "
        set -e

        docker pull nexus:8085/myapp:$CI_COMMIT_SHORT_SHA

        docker stop myapp || true
        docker rm myapp || true

        docker run -d \
          --name myapp \
          -p 8088:8080 \
          nexus:8085/myapp:$CI_COMMIT_SHORT_SHA
      "

Explanation:
Connects to 192.168.94.91 as deploy and runs the quoted deployment commands on the remote server. The remote script pulls the commit-specific image, replaces the existing myapp container, and starts the new container.

Options:
- -e = errexit behavior for set: Makes the shell exit when an unhandled command fails.
- || = shell logical OR operator: Runs true only if the docker stop or docker rm command fails.
- -d = --detach (detach): Runs the new container in the background.
- --name myapp = name: Assigns the container name myapp.
- -p 8088:8080 = --publish 8088:8080 (publish): Maps host port 8088 to container port 8080.
- \ = shell line continuation: Continues the same command on the next physical line.
------------------------------------------------------------
