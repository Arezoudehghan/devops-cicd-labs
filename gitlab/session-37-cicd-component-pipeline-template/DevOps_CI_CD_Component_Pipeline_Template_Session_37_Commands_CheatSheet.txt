------------------------------------------------------------
# sudo gitlab-rake gitlab:env:info | grep -i version

Explanation:
Runs the GitLab environment information task and filters its output for lines containing the word "version", ignoring letter case.

Options:
- | = shell pipe operator: Sends the output of the command on the left to the command on the right.
- -i = --ignore-case (ignore case): Makes grep match "version" without considering uppercase or lowercase letters.

------------------------------------------------------------
# docker build -f "${COMPONENT_DOCKERFILE}" -t "${COMPONENT_IMAGE_NAME}:${CI_COMMIT_SHORT_SHA}" .

Explanation:
Builds a Docker image from the current directory using the Dockerfile path stored in COMPONENT_DOCKERFILE and tags the image with the component image name and commit short SHA.

Options:
- -f = --file (file): Specifies the Dockerfile to use for the build.
- -t = --tag (tag): Applies the specified name and tag to the built image.
- . = current directory: Uses the current directory as the Docker build context.
------------------------------------------------------------

------------------------------------------------------------
# docker image inspect "${COMPONENT_IMAGE_NAME}:${CI_COMMIT_SHORT_SHA}" > /dev/null

Explanation:
Inspects the specified Docker image and discards the normal output. A successful exit status can be used to confirm that the image exists.

Options:
- > = shell output redirection operator: Redirects standard output to the file or device on the right.
- /dev/null = null device: Discards the redirected standard output.

------------------------------------------------------------
# CMD ["sh", "-c", "cat /app/app.txt && sleep 3600"]

Explanation:
Sets the container's default command to run a shell that prints /app/app.txt and then sleeps for 3600 seconds if the cat command succeeds.

Options:
- -c = command string: Tells sh to execute the following string as shell commands.
- && = shell AND operator: Runs sleep 3600 only if cat /app/app.txt succeeds.
- 3600 = sleep duration in seconds: Keeps the process running for one hour after the file is printed.
