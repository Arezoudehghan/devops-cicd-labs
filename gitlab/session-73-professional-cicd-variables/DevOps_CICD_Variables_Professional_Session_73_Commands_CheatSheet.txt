# docker login registry.example.com -u admin -p MySecretPassword

Explanation:
Logs in to the Docker registry at registry.example.com using the supplied username and password.

Options:
- -u = --username (username): Sets the registry username to admin.
- -p = --password (password): Supplies MySecretPassword directly as the registry password.

# docker build -t "myapp:$CI_COMMIT_SHORT_SHA" .

Explanation:
Builds a Docker image from the current directory and tags it with the current short commit SHA.

Options:
- -t = --tag (tag): Assigns the image name and tag myapp:$CI_COMMIT_SHORT_SHA.
- . = build context: Uses the current directory as the Docker build context.

# test -n "${DEPLOY_API_TOKEN:-}"

Explanation:
Checks that DEPLOY_API_TOKEN expands to a non-empty string. The command returns success when the value is not empty.

Options:
- -n = string is non-empty: Returns true when the following string has a length greater than zero.
- ${DEPLOY_API_TOKEN:-} = shell parameter expansion: Expands to DEPLOY_API_TOKEN when it is set and non-empty, otherwise expands to an empty string.

# printf '%s' "$MY_CONFIG" > config.txt

Explanation:
Writes the exact value of MY_CONFIG to config.txt without adding an automatic newline.

Options:
- %s = string format specifier: Prints the supplied MY_CONFIG value as a string.
- > = shell output redirection: Creates or overwrites config.txt with the command output.
