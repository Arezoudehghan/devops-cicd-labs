        docker stop $CI_PROJECT_NAME || true
        docker rm $CI_PROJECT_NAME || true

        docker run -d \
          --name $CI_PROJECT_NAME \
          --restart unless-stopped \

      "

Explanation:
Technical correction: the earlier CI/CD example mixed && with || true in a way that made failure handling unclear, so this corrected remote command uses set -e and separate deployment steps. It pulls the new image first, then stops and removes the old container and starts the new version on DEV-2.

Options:

- || = shell OR operator: Run true when docker stop or docker rm fails so a missing old container does not abort the deployment.
- -d = --detach (detach): Run the new container in the background.
- --name = container name: Use $CI_PROJECT_NAME as the container name.
- --restart = restart policy: Use unless-stopped as the restart policy.
- -p = --publish (publish): Publish host port 8088 to container port 5000.

# ssh deploy@192.168.94.91 "
        set -e

        IMAGE='192.168.94.90:8085/$CI_PROJECT_NAME:$CI_COMMIT_SHORT_SHA'
        CONTAINER='$CI_PROJECT_NAME'

        echo 'Pulling new image...'
        docker pull \$IMAGE

        echo 'Stopping old container...'
        docker stop \$CONTAINER || true

        echo 'Removing old container...'
        docker rm \$CONTAINER || true

        echo 'Starting new container...'
        docker run -d \
          --name \$CONTAINER \
          --restart unless-stopped \
          -p 8088:5000 \
          -e APP_ENV=production \
          -e APP_VERSION=$CI_COMMIT_SHORT_SHA \
          \$IMAGE

        echo 'Checking container...'
        docker ps --filter name=\$CONTAINER
      "

Explanation:
Runs the fuller deployment script on DEV-2 through SSH using remote IMAGE and CONTAINER variables. It pulls the new image, replaces the old container, starts the new container, and then displays the matching running container.

Options:
- -e in set -e = errexit shell option: Exit the remote shell when an unhandled command fails.
- || = shell OR operator: Run true when docker stop or docker rm fails so the deployment can continue when no old container exists.
- -d = --detach (detach): Run the new container in the background.
- --name = container name: Use the remote $CONTAINER variable as the container name.
- --restart = restart policy: Use unless-stopped as the restart policy.
- -p = --publish (publish): Publish host port 8088 to container port 5000.
- -e in docker run = --env (environment): Set APP_ENV and APP_VERSION inside the new container.
- --filter = filter output: Show docker ps results matching name=$CONTAINER.
- \$ = escaped dollar sign: Prevent local shell expansion so IMAGE and CONTAINER are expanded by the remote shell.
- \ = shell line continuation: Continue the docker run command on the next line.
