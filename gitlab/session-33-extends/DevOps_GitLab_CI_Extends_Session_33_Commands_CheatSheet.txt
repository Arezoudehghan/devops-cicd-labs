import yaml

with open(".gitlab-ci.yml") as f:
    yaml.safe_load(f)

print("YAML syntax OK")
PY

Explanation:
Runs an inline Python script that loads .gitlab-ci.yml with PyYAML and prints a success message if YAML parsing completes without an exception.

Options:
- - = standard-input script indicator: Tells Python to read the script from standard input.
- <<'PY' = quoted here-document operator: Passes all lines up to the closing PY marker to Python without shell expansion inside the here-document.
