# sudo grep -n "concurrent" /etc/gitlab-runner/config.toml

Explanation:
Searches the GitLab Runner configuration file for lines containing the word "concurrent" and prints their line numbers. sudo runs the command with elevated privileges.

Options:
- -n = --line-number (line number): Prefix each matching line with its line number.

# git log --oneline -5

Explanation:
Shows the most recent Git commits in a compact one-line format and limits the output to five commits.

Options:
- --oneline = one-line commit format: Shows each commit in a condensed single-line form.
- -5 = maximum 5 commits: Limits the displayed history to the five most recent commits.
