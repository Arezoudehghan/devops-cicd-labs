# mkdir -p monorepo-demo/services/{frontend,backend,worker}

Explanation:
Creates the monorepo-demo directory structure and the frontend, backend, and worker service directories in one command.

Options:
- -p = --parents (parents): Create parent directories as needed and do not report an error if they already exist.
- {frontend,backend,worker} = Bash brace expansion: Expands into three directory names: frontend, backend, and worker.

# docker build -t backend:$CI_COMMIT_SHORT_SHA services/backend

Explanation:
Builds a Docker image from services/backend and tags it as backend using the current GitLab short commit SHA.

Options:
- -t = --tag (tag): Apply a name and optional tag to the built image.
- backend:$CI_COMMIT_SHORT_SHA = tag value: Use backend as the image name and the GitLab CI/CD variable CI_COMMIT_SHORT_SHA as the image tag.
