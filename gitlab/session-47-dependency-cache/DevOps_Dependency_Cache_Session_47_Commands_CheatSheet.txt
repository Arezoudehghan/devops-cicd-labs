# sudo -u gitlab-runner -H bash -lc 'python3 --version'

Explanation:
Runs a login Bash shell as the gitlab-runner user and checks the Python version available to that user.

Options:
- -u gitlab-runner = --user=gitlab-runner: Runs the command as the gitlab-runner user.
- -H = --set-home: Sets HOME to the target user's home directory.
- -l = --login: Starts Bash as a login shell.
- -c 'python3 --version' = command string: Tells Bash to execute the quoted command string.
- --version = version: Prints the Python version and exits.

# sudo -u gitlab-runner -H bash -lc 'node --version && npm --version'

Explanation:
Checks the Node.js and npm versions available to the gitlab-runner user. The npm check runs only if the Node.js check succeeds.

Options:
- -u gitlab-runner = --user=gitlab-runner: Runs the command as the gitlab-runner user.
- -H = --set-home: Sets HOME to the target user's home directory.
- -l = --login: Starts Bash as a login shell.
- -c 'node --version && npm --version' = command string: Tells Bash to execute the quoted command string.
- --version = version: Prints the version for both node and npm when each command runs.
- && = AND operator: Runs the second command only if the first command exits successfully.
------------------------------------------------------------

# du -sh .cache/pip || true

Explanation:
Shows the total size of the .cache/pip directory in a human-readable form. If du fails, true prevents the shell command from returning a failure status.

Options:
- -s = --summarize (summarize): Displays only a total for the specified path.
- -h = --human-readable (human-readable): Prints sizes using units such as K, M, and G.
- || = OR operator: Runs true only if the du command fails.

Options:
- -type f = file type predicate: Matches regular files only.
- -name cache.zip = name predicate: Matches entries whose basename is cache.zip.
- -print = print action: Writes each matching pathname to standard output.
