# sudo systemctl status gitlab-runner --no-pager

Explanation:
Shows the current status of the gitlab-runner systemd service. sudo runs systemctl with elevated privileges.

Options:
- --no-pager = no pager: Prints the output directly instead of opening it in a pager.
------------------------------------------------------------

# docker build -t myapp .

Explanation:
Builds a Docker image from the build context in the current directory and names the resulting image myapp.

Options:
- -t = --tag (tag): Names and optionally tags the image; myapp is the image name used here.
- . = build context path: Uses the current directory as the Docker build context.
