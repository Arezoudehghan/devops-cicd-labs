- -f = --force (force): Forces removal of the existing myapp-development container.
- 2>/dev/null = stderr redirection: Sends standard error from docker rm to /dev/null.
- || = shell OR operator: Runs true if docker rm does not remove a container.
- -d = --detach (detach): Runs the new container in the background.
- --name = container name option: Sets the container name to myapp-development.
- --restart = restart policy option: Uses unless-stopped so Docker restarts the container unless it was explicitly stopped.
