------------------------------------------------------------
# docker run -d \
  --name myapp \
  -p 8088:8080 \
  nexus.example.local:8085/myapp:v2.0.0

Explanation:
Starts the `v2.0.0` application container in the background and publishes it on host port `8088`.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name myapp = container name: Assigns the name `myapp` to the container.
- -p = --publish (publish): Publishes container port `8080` on host port `8088`.
- \ = shell line continuation: Continues the same command on the next line.

# curl -f http://127.0.0.1:8082/health

Explanation:
Checks the Green application's health endpoint and returns an error status if the HTTP request fails.

Options:
- -f = --fail (fail): Makes curl return an error for HTTP response codes of 400 or higher and suppresses the response body for those server errors.
