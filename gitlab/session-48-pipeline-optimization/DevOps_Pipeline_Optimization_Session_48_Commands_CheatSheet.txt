# sudo ls -lah /home/gitlab-runner/cache/

Explanation:
Runs ls with elevated privileges and shows detailed information for all entries in /home/gitlab-runner/cache/ with human-readable sizes.

Options:
- -l = long listing format: Displays detailed file information.
- -a = --all: Includes entries whose names begin with a dot.
- -h = --human-readable: Shows file sizes in readable units such as KiB, MiB, and GiB.
------------------------------------------------------------
# sudo du -sh /home/gitlab-runner/cache/

Explanation:
Runs du with elevated privileges and shows the total disk space used by /home/gitlab-runner/cache/ in human-readable form.

Options:
- -s = --summarize: Displays only the total size for the specified path.
- -h = --human-readable: Shows sizes in readable units such as KiB, MiB, and GiB.
